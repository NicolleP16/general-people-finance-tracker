# General People Finance Tracker

Aplicación web para la gestión de finanzas personales.

## Stack tecnológico

- Backend: Python + Django
- Frontend: React + Tailwind CSS
- Base de datos: Supabase
- Contenedores: Docker + Docker Compose
- Backend testing: Pytest
- Frontend testing: Vitest
- E2E testing: Selenium
- CI/CD: GitHub Actions
- Code Quality: SonarCloud

## Estructura del proyecto

- `backend/`: API y lógica de negocio.
- `frontend/`: interfaz de usuario.
- `infrastructure/`: configuraciones de infraestructura.
- `docs/`: documentación técnica.
- `.github/workflows/`: pipelines de automatización.

## Funcionalidades del MVP

- Registro e inicio de sesión.
- Registro, edición y eliminación de transacciones.
- Clasificación de ingresos y gastos.
- Presupuestos mensuales por categoría.
- Alertas de presupuesto.
- Reportes financieros.
- Administración de categorías.
